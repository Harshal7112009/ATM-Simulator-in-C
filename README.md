# ATM Simulator in C

A terminal-based ATM machine simulation program built using core C programming concepts.

## 🚀 Features Included
* **Secure PIN Verification:** Validates user access before entering the main system.
* **Account Type Selection:** Allows users to choose between a **Savings** or **Current** account.
* **Dynamic Transactions:** Real-time money deposit and withdrawal operations.
* **Balance Tracking:** Updates and checks the user's account balance instantly.

## 🛠️ Concepts Practiced
* Primary Data Types (`int`, `float`)
* Decision Control Structure (`if-else`, `else if`)
* Switch Case Control Structure
* Loop Control Structure (`while` loop)
* Break and Continue Statements
